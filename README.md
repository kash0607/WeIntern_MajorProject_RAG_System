# Production RAG System

A Production-ready Retrieval-Augmented Generation (RAG) System built using Python, LangChain, ChromaDB, and Sentence Transformers.

## Features Completed (Day 1)

- PDF Document Loading
- Fixed-size Chunking
- Recursive Chunking
- Embedding Generation
- ChromaDB Vector Storage

## Tech Stack

- Python
- LangChain
- ChromaDB
- Sentence Transformers
- PyPDFLoader
